# Trakya Teknik Makine Kurumsal Web Sitesi Demo

Proaktif satış görüşmesinde gösterilmek üzere Trakya Teknik Makine'nin kurumsal kimliğini, Disan Hidrolik Makine Trakya Bölge Yetkili Servisi statüsünü ve 3 approved hizmetini (`Yedek Parça Temini`, `Yerinde Teknik Destek`, `Makine Bakım ve Onarım`) modern, responsive ve güven veren bir görsel sunumla ortaya koyan kurumsal frontend demo projesidir.

## 2. Hızlı Başlangıç (Quick Start)

Bu proje sıfır ağır derleme bağımlılığına sahip modern Vanilla HTML/CSS/JS projesidir.

1. Depoyu yerel bilgisayarınıza klonlayın veya indirin.
2. `index.html` dosyasını herhangi bir modern web tarayıcısında (Chrome, Firefox, Edge, Safari) doğrudan açın VEYA yerel bir dev server ile (örn: VS Code Live Server veya `npx serve .`) çalıştırın.

---

## 3. Çalıştırma Komutları

```bash
# Yerel geliştirme sunucusu başlatmak için (opsiyonel):

```
