# Trakya Teknik Makine Kurumsal Web Sitesi Demo

Trakya Teknik Makine firmanın ne yaptığını, Disan Hidrolik Makine Trakya Bölge Yetkili Servisi statüsünü ve üç onaylı hizmetini (`Yedek Parça Temini`, `Yerinde Teknik Destek`, `Makine Bakım ve Onarım`) profesyonel, modern ve güven veren bir kurumsal frontend demoya dönüştüren landing page çalışmasıdır (`delivery_profile: Prototype`).

## 1. Hızlı Başlangıç (Quick Start)

Bu proje client-side Vanilla HTML5/CSS3/ES6 mimarisine sahiptir. Herhangi bir ağır derleme/build adımı gerektirmez.

```bash
# 1. Proje klasörüne gidin
cd outputs/demos/trakya-teknik-makine/latest/

# 2. Herhangi bir yerel statik HTTP sunucusu ile çalıştırın
npx serve .
# Veya tarayıcıda doğrudan index.html dosyasını açın.
```

## 2. Çalıştırma Komutları

```bash
# Statik sunucu başlatma
npx serve .

# Python HTTP server alternatifi
python -m http.server 8000
```
