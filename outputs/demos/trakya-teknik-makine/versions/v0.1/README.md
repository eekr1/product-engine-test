# Trakya Teknik Makine Kurumsal Web Sitesi Demo

Trakya bölgesinde makine bakım/onarım, yedek parça temini ve yerinde teknik destek arayan endüstriyel işletmelere Trakya Teknik Makine'nin uzmanlığını ve Disan Hidrolik Makine Trakya Bölge Yetkili Servisi statüsünü sunan modern, güven veren kurumsal frontend web sitesi demosu.

## 1. Hızlı Başlangıç (Quick Start)

1. Depoyu klonlayın veya çalışma dizinine gidin.
2. Gerekli bağımlılıkları yükleyin: `npm install`
3. Geliştirme sunucusunu başlatın: `npm run dev`
4. Tarayıcıda görüntüleyin: `http://localhost:5173`

## 2. Çalıştırma Komutları

```bash
# Bağımlılıkları yükleme
npm install

# Yerel geliştirme sunucusu (Vite dev server)
npm run dev

# Demo build üretme
npm run build

# Build önizleme
npm run preview
```
