# Trakya Teknik Makine Kurumsal Web Sitesi Yenileme Demo

Trakya Teknik Makine'nin mevcut kurumsal web sitesindeki firma ve hizmet bilgilerini koruyarak, firmanın hizmetlerini daha profesyonel ve güven veren biçimde sunan modern bir frontend demo projesi. Satış görüşmelerinde gösterilebilir kalitede ve responsive bir kullanıcı deneyimi sunar.

---

## 1. Hızlı Başlangıç (Quick Start)

1. Depoyu klonlayın ve proje kök dizinine geçin:
   ```bash
   cd trakya-teknik-makine
   ```
2. Gerekli bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
3. Yerel geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
4. Tarayıcınızda `http://localhost:5173` (veya belirtilen dev port) adresini açarak demoyu inceleyin.

---

## 2. Çalıştırma Komutları

| Komut | Açıklama |
|---|---|
| `npm run dev` | Yerel geliştirme ve canlı önizleme sunucusunu başlatır |
| `npm run build` | Üretim (production) için optimize edilmiş bundle oluşturur |
| `npm run preview` | Oluşturulan üretim bundle'ını yerelde test eder |
