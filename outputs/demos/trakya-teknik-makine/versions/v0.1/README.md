# Trakya Teknik Makine Kurumsal Web Sitesi Yenileme Demo — Proje Rehberi

Trakya Teknik Makine'nin mevcut kurumsal web sitesini modernleştiren, firmanın Disan Hidrolik Trakya Bölge Yetkili Servisi gücünü ve 3 ana hizmetini (Yedek Parça Temini, Yerinde Teknik Destek, Makine Bakım ve Onarım) satış görüşmesinde en etkili biçimde sunan frontend demo projesidir.

---

## 1. Hızlı Başlangıç (Quick Start)

Bu proje Product Engine `demo-frontend` paketi uyarınca hafif ve bağımsız bir frontend uygulaması olarak tasarlanmıştır.

1. Depoyu klonlayın veya proje klasörünü açın.
2. Bağımlılık kurulumu veya özel backend sunucusu gerektirmez.
3. `index.html` dosyasını doğrudan tarayıcınızda açarak veya bir statik web sunucusu (ör. `npx serve` veya VS Code Live Server) ile hemen çalıştırabilirsiniz.

---

## 2. Çalıştırma Komutları

```bash
# Seçenek 1: Doğrudan tarayıcıda açın
open index.html # macOS
start index.html # Windows

# Seçenek 2: Lokal statik sunucu ile çalıştırma (opsiyonel)
npx serve ./
```
