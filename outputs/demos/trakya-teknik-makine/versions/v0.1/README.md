# Trakya Teknik Makine Kurumsal Web Sitesi Demo

Trakya Teknik Makine'nin kurumsal kimliğini, Disan Hidrolik Makine Trakya Bölge Yetkili Servisi statüsünü ve 3 approved hizmetini (`Yedek Parça Temini`, `Yerinde Teknik Destek`, `Makine Bakım ve Onarım`) proaktif satış görüşmelerinde etkileyici biçimde sergileyen modern kurumsal frontend demo sitesidir.

## 1. Hızlı Başlangıç (Quick Start)

Bu proje bağımsız bir frontend demo paketidir. Herhangi bir ağır derleme veya veritabanı kurulumu gerektirmez.

1. Proje dizinini bir yerel web sunucusu (veya doğrudan tarayıcı static preview ortamı) ile açın.
2. `index.html` dosyasını tarayıcınızda görüntüleyin.
3. Veri akışı `src/services/dataService.js` adapter'ı ve `src/data/mockData.js` deposu üzerinden otomatik sağlanır.
