# Trakya Teknik Makine Kurumsal Web Sitesi Yenileme Demo

Trakya Teknik Makine'nin mevcut kurumsal web sitesindeki doğrulanmış firma bilgilerini (Disan Hidrolik Trakya Bölge Yetkili Servisliği, Yedek Parça Temini, Yerinde Teknik Destek, Makine Bakım ve Onarım) koruyarak, potansiyel müşteri satış görüşmesinde güçlü bir ilk izlenim bırakacak modern, profesyonel ve responsive bir frontend web demosu.

## 1. Hızlı Başlangıç (Quick Start)

Bu proje bağımsız bir frontend satış demosudur. Herhangi bir ekstra veritabanı veya ağır bağımlılık gerektirmeden lokal ortamda doğrudan önizlenebilir.

1. Depoyu yerel bilgisayarınıza klonlayın veya indirin.
2. Proje kök dizininde `index.html` dosyasını bir web tarayıcısında açın veya basit bir lokal statik sunucu (ör. `npx serve` veya Vite) çalıştırın.
3. Tarayıcınızda demoyu responsive (masaüstü, tablet, mobil) boyutlarda inceleyebilirsiniz.

## 2. Çalıştırma Komutları

```bash
# Önizleme için basit bir lokal sunucu başlatmak isterseniz:
npx serve .

# Veya herhangi bir statik sunucu / canlı önizleme aracı kullanılabilir.
```
