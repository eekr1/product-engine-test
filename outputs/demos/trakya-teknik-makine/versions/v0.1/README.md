# Trakya Teknik Makine Kurumsal Web Sitesi Yenileme Demo

Trakya Teknik Makine'nin yayındaki mevcut web sitesini, firmanın uzmanlığını ve Disan Hidrolik yetkili servisliğini daha modern, güven veren ve etkileyici bir frontend demo ile yeniden sunan proaktif bir satış prototipidir.

---

## 1. Hızlı Başlangıç (Quick Start)

Bu proje Vite ile yapılandırılmış modüler bir HTML5/Vanilla JS/CSS3 frontend uygulamasıdır.

```bash
# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev

# Satış demosu preview sunucusunu çalıştırın
npm run preview
```

---

## 2. Çalıştırma ve Test Komutları

- `npm run dev`: Geliştirme sunucusunu başlatır (Vite).
- `npm run build`: Production/Demo paketini derler (`dist/`).
- `npm run preview`: Derlenmiş demoyu lokal sunucuda önizler.
