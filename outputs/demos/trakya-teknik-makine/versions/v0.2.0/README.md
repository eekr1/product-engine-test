# Trakya Teknik Makine Kurumsal Web Sitesi Yenileme Demo

Trakya Teknik Makine'nin mevcut kurumsal web sitesini (`https://www.trakyateknikmakine.com/`), doğrulanmış firma, hizmet ve Disan Hidrolik yetkili servislik bilgilerini koruyarak modern, responsive ve yüksek kurumsal güven sunan bir frontend satış demosu olarak yeniden ele alma çalışması.

---

## 1. Hızlı Başlangıç (Quick Start)

Bu proje Product Engine `v0.2.0` standartlarına uygun olarak modüler frontend mimarisi ve clean service boundary ile hazırlanmıştır.

```bash
# Proje dokümantasyon paketini incelemek ve çalıştırmak için:
# 1. Kanonik okuma sırasını takip edin (Bkz. Bölüm 3).
# 2. Aktif dalgaya (WAVE_00) ilişkin planı uygulayın.
```
