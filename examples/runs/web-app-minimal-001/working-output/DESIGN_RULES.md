## 1. Visual Language & Theme

- **Theme:** Modern Dark Mode.
- **Primary Background:** Slate Dark (`#0f172a`).
- **Surface Accent:** Violet/Indigo Gradient (`#6366f1` to `#8b5cf6`).

## 2. UI Components & Layout

- **Card Container:** Rounded borders (`border-radius: 8px`), subtle shadow.
- **Filter Pills:** Active state highlighted with Indigo accent background.
