# Task Tracker Demo App

Task Tracker Demo App, bireysel geliştiricilerin ve küçük ekiplerin günlük görevlerini hızlıca ekleyebileceği, durumlarını güncelleyebileceği ve filtreleyebileceği modern, koyu temalı bir web uygulaması prototipidir.

## Özellikler

- **Görev Yönetimi:** Yeni görev ekleme, silme ve durum güncelleme (`Yapılacak`, `Devam Ediyor`, `Tamamlandı`).
- **Anlık Filtreleme:** Görevleri duruma göre filtreleme ve hızlı arama.
- **Yerel Depolama:** Sunucu bağımlılığı olmadan verileri tarayıcı `localStorage` üzerinde saklama.
- **Koyu Tema Arayüzü:** Indigo/Violet vurgulu modern dark-mode tasarımı ve responsive düzen.

## Proje Dokümantasyonu

Projenin teknik bağlamı ve iş kuralları aşağıdaki belgelerde tanımlanmıştır:

- [PRODUCT_RULES.md](file:///examples/outputs/web-app-minimal-001/PRODUCT_RULES.md) — Görev yaşam döngüsü ve iş kuralları.

## Hızlı Başlangıç

1. Repository'yi klonlayın.
2. `index.html` dosyasını tarayıcıda açın veya `npm run dev` ile yerel geliştirme sunucusunu başlatın.
