# Design Documentation

Bu klasörde Vibehall'ın tüm tasarım referansları bulunur. Bu belgeler, Wave dosyalarının referans verdiği canonical design documentation kaynağıdır.

## Kullanım Kuralları

- Her ekran yalnızca tek Markdown dosyasında tanımlanır.
- Aynı tasarım bilgisi iki dosyada bulunmamalıdır.
- Wave dosyaları bu klasöre referans verir.
- Yeni tasarım eklenecekse önce ilgili dosya güncellenir.
- Bu klasör tasarımın tek doğru kaynağıdır.

## Başlık Standardı

- `#`: Doküman başlığı; dosyada yalnızca bir kez kullanılır.
- `##`: Numaralı ana bölümler ve referansın niteliği.
- `###`: Numaralı alt bölümler veya ana bölüme bağlı konu başlıkları.
- `####`: Alt bölüm içindeki bağlamsal ayrımlar.

Aynı kavram için aşağıdaki kararlı başlık adları kullanılır:

- `Responsive Davranış`
- `Erişilebilirlik`
- `Azaltılmış Hareket`
- `Temsilî Alanlar`
- `Otomatik Uygulanmayacak Görsel Unsurlar`
- `Yasaklanan Yorumlar`
- `Teknik Uyarlama Alanları`
- `Mevcut Teknik Yapıyla Uyum`
- `Performans Yaklaşımı`
- `Wave Kapsamı Önerisi`
- `Görsel Kabul Kriterleri`
- `Son Tasarım Hükmü`
