# Trakya Teknik Makine Kurumsal Web Sitesi Demo

Trakya Teknik Makine'nin gerçek firma ve hizmet bilgilerini (Disan Hidrolik Makine Trakya Bölge Yetkili Servisi) profesyonel, modern ve güven veren biçimde sunan kurumsal frontend web satış demosu.

## 1. Hızlı Başlangıç (Quick Start)

Bu proje bağımsız, hafif ve çevrimdışı çalıştırılabilir (offline-capable) modern bir frontend web uygulamasıdır.

1. Depoyu klonlayın veya proje klasörünü açın.
2. `index.html` dosyasını doğrudan herhangi bir modern web tarayıcısında (Chrome, Edge, Safari, Firefox) açın veya yerel bir statik web sunucusu çalıştırın:
   ```bash
   npx serve .
   ```
3. Web tarayıcınızda `http://localhost:3000` adresine gidin.

## 2. Çalıştırma ve Önizleme Komutları

- **Statik Sunucu Başlatma**: `npx serve .` veya `python -m http.server 8080`
- **Vite Dev Sunucusu (İsteğe Bağlı)**: `npx vite`
