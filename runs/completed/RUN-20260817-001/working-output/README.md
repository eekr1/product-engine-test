# Fizyoterapist Eda Pala Web Sitesi Demo

Fizyoterapist Eda Pala için Tekirdağ konum bağlamında doğrulanmış bilgilerle hazırlanan, modern, güven veren ve proaktif satış görüşmelerinde sergilenebilecek profesyonel kişisel web sitesi demosudur.

Approved Facts Baseline:
- **İsim:** Eda Pala
- **Mesleki Unvan:** Fizyoterapist
- **Konum Bağlamı:** Tekirdağ
- **Onaylı Outbound Instagram:** https://www.instagram.com/fizyoterapistedapala?igsh=aXNtbGgyZ3hwbzVv

## 1. Hızlı Başlangıç (Quick Start)

Bu proje bağımsız, modüler ve statik bir frontend demo uygulamasıdır. Herhangi bir veritabanı veya backend servisi gerektirmez.

1. Proje dizinini açın.
2. Web sunucusu ile statik dosyaları sunun veya `index.html` dosyasını doğrudan modern bir tarayıcıda açın.
3. Sosyal medya outbound yönlendirmelerini incelemek için Instagram bağlantısını test edin.

## 2. Çalıştırma Komutları

```bash
# Statik yerel önizleme sunucusu başlatmak için (isteğe bağlı)
npx serve .

# veya doğrudan tarayıcı ile çalıştırmak için
open index.html
```
