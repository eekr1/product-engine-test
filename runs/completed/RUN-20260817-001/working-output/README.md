# Fizyoterapist Eda Pala Web Sitesi Demo

Tekirdağ'daki Fizyoterapist Eda Pala için, doğrulanmış factual verilerle (İsim: Eda Pala, Mesleki Unvan: Fizyoterapist, Konum: Tekirdağ, Outbound Instagram URL'si) çalışan; modern, güven veren ve profesyonel bir frontend web sitesi demosu (landing page).

## 1. Hızlı Başlangıç (Quick Start)

Bu proje static HTML, CSS ve JavaScript tabanlı modüler local configuration yapısıyla çalışır.

1. Depoyu klonlayın veya indirin.
2. Herhangi bir static web sunucusu (veya VS Code Live Server / Vite / python -m http.server) ile proje kök dizinini sunun.
3. Tarayıcıda `index.html` sayfasını açın.

## 2. Çalıştırma Komutları

```bash
# Yerel geliştirme sunucusu başlatma (Örnek Python static server):
python -m http.server 3000

# Veya Node static server:
npx serve .
```
