# Trakya Teknik Makine Kurumsal Web Sitesi Demo

Trakya Teknik Makine'nin kurumsal kimliğini, Disan Hidrolik Makine Trakya Bölge Yetkili Servisliği unvanını ve 3 approved hizmetini potansiyel müşteri ve satış görüşmelerinde etkileyici biçimde sunan modern kurumsal frontend demo projesidir.

## 1. Hızlı Başlangıç (Quick Start)

Proje saf Web Standartları (HTML5, Vanilla CSS3, Vanilla JS ES6 Modules) kullanılarak geliştirilmiştir. Ağır harici kütüphane veya karmaşık build adımları gerektirmez.

1. Depoyu yerel bilgisayarınıza klonlayın veya indirin.
2. `index.html` dosyasını doğrudan herhangi bir modern web tarayıcısında (Chrome, Firefox, Edge, Safari) açın.
3. Veya yerel bir geliştirme sunucusu (Vite, Live Server vb.) kullanın:
   ```bash
   npx vite
   # veya
   python -m http.server 8000
   ```

## 2. Çalıştırma Komutları

```bash
# Yerel geliştirme sunucusunu başlatmak için:
npm run dev

# Uygulamayı önizlemek için:
npm run preview
```
